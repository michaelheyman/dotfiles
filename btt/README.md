# bettertouchtool

[BetterTouchTool](https://folivora.ai/) is an app that allows you to customize various input
devices on your Mac.

## Importing Preset

Verify that BetterTouchTool has been installed on your system. Once installed, open it and
import the preset by navigating to:

1. Presets
2. Import Presets
3. Navigate to `~/.local/applications/bettertouchtool`

Then your custom configuration will be loaded.
